## 一、最终结论（可直接引用）

### 1. 构念成立：计算问题解决不能等同于学业能力

三科（数学、阅读、科学）的三次多项式回归可解释 CMPS 方差的 **65.0%**（10 组似真值范围 64.9%–65.1%），**剩余 35% 是"学业基线之外"的部分**。这为"相对超额表现"提供了构念基础——LDW 得分里有三分之一强的变异无法由学业能力还原。

### 2. 绝对表现与相对表现是两件不同的事

| 指标 | 中国四省市 | 说明 |
|---|---|---|
| CMPS 绝对分 | **560.7（第 3 / 84）** | 数学第 1（612.8） |
| 相对残差排名 | **第 77 / 83** | 低于自身学业基线预测 **−27.6 分** |
| CMPS−数学 分差 | **−52.1（83 个体系中最低）** | 量表未等值，仅作描述 |

对照：马来西亚绝对分仅第 38，相对表现却排**第 1**（+45.6 分）。这说明"高分"与"超出预期"是两个不同维度，不能互相替代。

### 3. 家庭 SES 对"超额"几乎没有作用（H1 成立，且强于预期）

| 因变量 | ESCS 标准化梯度均值（81 个体系） |
|---|---|
| CMPS 原始分 | 0.257 |
| 数学 | 0.335 |
| 阅读 | 0.299 |
| 科学 | 0.328 |
| **相对表现** | **−0.030** |

SES 对 CMPS 的梯度，几乎全部经由学业成绩传导。控制学业成绩后，SES 对相对表现的效应为 **−0.012（SE 0.001, p<.001）**——不是正，而是微幅为负。

ESCS 五分位上的超额率：27.0% → 26.2% → 25.3% → 24.6% → **23.6%**（单调下降）。

### 4. 核心发现：学校资源使 SES 斜率**反号**（H3 成立）

控制学校层变量后的跨层交互（多层模型，10 组似真值 Rubin 合并，N=520,904）：

| 项 | 系数 | SE | p |
|---|---|---|---|
| ESCS | −0.0325 | 0.0028 | <.001 |
| **ESCS × 数字资源短缺** | **+0.0103** | 0.0016 | <.001 |
| **ESCS × 县镇及以下** | **+0.0176** | 0.0032 | <.001 |
| ESCS × 计算机俱乐部 | −0.0017 | 0.0019 | .370 |

**Johnson–Neyman 分析给出了明确的翻转点：**

| 学校数字资源短缺 z | ESCS 斜率 | t | 含义 |
|---|---|---|---|
| −2（资源很充足） | **−0.0356** | −5.01 | 补偿：弱势学生更多超额 |
| −1（较充足） | −0.0197 | −4.16 | 补偿 |
| 0（平均） | −0.0037 | −1.17 | 无效应 |
| +1（严重短缺） | **+0.0123** | +3.34 | 放大：优势学生更多超额 |
| +2（极度短缺） | **+0.0283** | +4.92 | 放大 |

**斜率由负转正的临界点 z = +0.23，约在第 61 百分位。** 即约六成学校处于"补偿"一侧，约四成处于"放大"一侧。

在二分类结局（是否进入体系内前 25%）下，交互同样显著，但表现为**梯度被削弱至零**而非真正反号（−1.9pp/SD → −0.3pp/SD）。连续结局才出现完整反号。这一差异已在稿中如实写明。

### 5. 超额是策略性的，不是猜的（H2 成立）

过程子样本（N=196,705，R²=0.234）：

| 预测变量 | 系数 | SE |
|---|---|---|
| 总用时（z） | **+0.3105** | 0.0090 |
| 每题操作次数（z） | **+0.0810** | 0.0075 |
| 放弃作答比例 | **−1.0630** | 0.0459 |
| 首操作潜伏期（秒） | **−0.0074** | 0.0005 |

超额者的行为特征是：**用时更长、操作更多、放弃更少、动手更快**。若超额源于猜测，方向应完全相反。逐步回归显示：仅 ESCS 解释 0.03% 方差，加入行为变量后升至 23.4%——家庭背景的解释力比行为参与低三个数量级。

### 6. 体系异质性极大（RQ4）

81 个体系中：**46 个补偿型**（斜率显著为负）、**25 个放大型**（显著为正）、10 个无显著差异。斜率 SD = 0.078。

- 与 CMPS 均值相关 **r = −0.715**（高表现体系倾向补偿）
- 与 ESCS 均值相关 r = −0.527
- 与 ESCS 离散度相关 r = +0.468

放大型体系集中于拉美、中亚高加索、部分东南亚与中东，**以及中国四省市**——中国是绝对分前十名中**唯一**斜率为正的体系。

### 7. 稳健性

| 设定 | ESCS | ×短缺 | ×县镇 |
|---|---|---|---|
| 基准 | −0.0203*** | +0.0121*** | +0.0268*** |
| 仅控数学的残差 | −0.0136** | +0.0116*** | +0.0379*** |
| 剔除快速作答者 | −0.0199*** | +0.0120*** | +0.0268*** |
| 剔除中国 | −0.0242*** | +0.0136*** | +0.0293*** |
| 超额定义改 z≥1 | −0.0068*** | +0.0011 | +0.0080*** |

方向一致，量级稳定。z≥1 设定下短缺交互不显著（尾部样本少），已如实报告。

## 二、研究设计的三处关键调整（相对最初方案）

| 原设计 | 实际执行 | 原因 |
|---|---|---|
| 三层模型（学生—学校—教师） | **两层** | 教师问卷仅覆盖 19 个经济体，中国 `QCI` 记录数为 **0** |
| 因变量为 LDW 综合分 | **CMPS 似真值 `PV1-10CMPS`**（在学生文件中，不在 LDW 文件内） | 实测文件结构 |
| 过程数据为汇总指标 | **题目级**：得分、用时、操作次数、首操作时间、放弃码 | LDW 文件提供 211 个题目级变量 |

另需注意：`SC261` 软件覆盖是 **1–5 等级序变量**（None / 1–25% / 26–50% / 51–75% / 76–100%），不是百分比；α = 0.88（19,083 校）。`S` 计分码为 0–5 六级部分给分，9 = Disengaged，r = Not reached——后两者本身就是行为指标。`TT`/`F` 单位为**毫秒**。

## 三、数据与样本

| 层级 | 规模 |
|---|---|
| 学生问卷总人数 | 755,721（90 个单元） |
| 有 CMPS 似真值 | 721,036（**84 个经济体**） |
| 基础分析样本（含 ESCS 与学校 ID） | 624,145（77 个体系，22,839 校） |
| 含学校层变量样本 | 520,904（74 个体系，18,528 校） |
| 过程子样本 | 226,348（84 个体系；中国 3,967） |
| 中国四省市 | 12,385 人 / 374 校 |

**过程子样本代表性**：覆盖率 31.3%，各体系 SD 仅 1.3pp；CMPS 标准化均差 0.007，ESCS 0.005，城乡构成完全一致——可视为随机子样本。

**样本损失必须交代**：澳门、冰岛、卢森堡、马耳他、斯洛文尼亚**无学校识别码**（不能进多层模型，澳门是 CMPS 第一名）；哥斯达黎加、萨尔瓦多**无 ESCS**；乌兹别克斯坦缺成就数据。性别变量在 14 个体系（澳大利亚、加拿大、德国、西班牙、荷兰、比利时、丹麦、冰岛、爱尔兰、新西兰，以及阿根廷、智利、哥伦比亚、乌拉圭）**全部编码 99（no response），而非 97（not administered）**，且无任何体系出现部分缺失——属体系层面未提交该变量，不是学生未作答，故无法用加权或插补补救，未纳入主模型。中国 12,385 人该变量全部有效。
